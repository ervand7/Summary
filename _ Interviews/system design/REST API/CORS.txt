## CORS (Cross-Origin Resource Sharing)

Browser security mechanism that controls whether frontend can access a backend on a different origin.

- Origin: Protocol + domain + port (`https://site.com:443`).
- CORS misconfigured: Browser blocks frontend from accessing the backend response.
- Preflight: Browser sends `OPTIONS` to backend to check if the actual request is allowed.
- Preflight denied: Browser doesn't send the actual request.
- Without preflight: Request reaches backend, but browser may block frontend from reading the response.
- Important: CORS only applies to browsers, not `curl`, Postman, or backend-to-backend requests.
