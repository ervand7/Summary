AWS Serverless lets you build applications without managing servers.

AWS automatically handles:
- Infrastructure and maintenance
- Scaling and availability
- Resource provisioning

Pricing: Pay based on usage instead of idle capacity.

Common AWS serverless services:
- Lambda: Run code on events
- API Gateway: Expose HTTP APIs
- DynamoDB: NoSQL database
- S3: Object storage
- SQS / SNS / EventBridge: Messaging and events
- Step Functions: Workflow orchestration

In short: You focus on business logic while AWS manages the infrastructure.
