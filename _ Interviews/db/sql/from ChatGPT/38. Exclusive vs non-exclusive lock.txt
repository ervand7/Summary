- Exclusive lock - запрещает конфликтующие операции. Например, `ALTER TABLE users ADD COLUMN age INT`
использует `ACCESS EXCLUSIVE`, блокируя чтение и запись таблицы.

- Non-exclusive lock - разрешает совместный доступ, ограничивая конфликтующие операции. Например,
`UPDATE users SET age = 25 WHERE id = 1` блокирует изменение этой строки другими транзакциями, но
разрешает её чтение и изменение других строк.
