### Cache Stampede (Thundering Herd)

Occurs when many concurrent requests miss the cache and simultaneously hit the DB, potentially causing overload.

Example:
- Hot key expires.
- 1,000 requests miss the cache.
- All query the DB → overload.

### Prevention

1. Request Coalescing (Singleflight): One request fetches data per key; others wait.
2. TTL Jitter: Randomize expiration to prevent multiple keys expiring simultaneously.
3. Background Refresh: Refresh popular keys before expiration.
4. Stale-While-Revalidate: Serve stale data while refreshing asynchronously.
5. Distributed Lock: Only one replica refreshes a key across all instances.

Interview Takeaway: Use singleflight for concurrent misses on the same key, TTL jitter for mass expiration, 
and background refresh to prevent cache misses.
