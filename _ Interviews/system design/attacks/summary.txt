## 1. CSRF (Cross-Site Request Forgery)
Attacker tricks a logged-in user's browser into sending unwanted requests using automatically attached cookies.

- Example: Unauthorized money transfer.
- Prevention: CSRF tokens, SameSite cookies.

## 2. XSS (Cross-Site Scripting)
Attacker injects malicious JavaScript into a website.

- Example: Stealing tokens or performing actions as the user.
- Prevention: Output escaping, CSP, HttpOnly cookies.

## 3. SQL Injection
Attacker manipulates SQL queries through user input.

- Example: `' OR 1=1 --`
- Prevention: Parameterized queries (prepared statements).

## 4. IDOR (Insecure Direct Object Reference)
User accesses another user's resources by changing an ID.

- Example: `/orders/123` → `/orders/124`
- Prevention: Backend authorization and ownership checks.

## 5. JWT / Authentication Vulnerabilities
Improper token validation allows unauthorized access.

- Example: Accepting expired or forged JWTs.
- Prevention: Verify signature, expiration (`exp`), issuer (`iss`), audience (`aud`).

## 6. Replay Attacks
Attacker resends a previously valid request.

- Example: Repeating a payment request.
- Prevention: Nonces, timestamps, replay protection, idempotency keys.

## 7. DoS (Denial of Service)
Attacker exhausts server resources with excessive requests.

- Example: Thousands of requests creating unlimited goroutines.
- Prevention: Rate limiting, timeouts, bounded worker pools.

## 8. Race Conditions
Concurrent requests exploit non-atomic business operations.

- Example: Two withdrawals spending the same balance.
- Prevention: DB transactions, locks, atomic updates.
