AWS-maintained libraries that simplify Lambda development.

- Logging: Structured JSON logs and correlation IDs.
- Metrics: Custom CloudWatch metrics.
- Tracing: AWS X-Ray integration.
- Idempotency: Safe retries using DynamoDB.
- Batch Processing: Handle partial SQS batch failures.

Interview answer: "AWS Lambda Powertools reduces boilerplate by providing reusable utilities
for logging, metrics, tracing, and idempotency."
