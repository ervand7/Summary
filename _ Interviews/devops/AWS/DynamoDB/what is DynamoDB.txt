## DynamoDB - key points

- NoSQL database; design tables around how the app reads and writes data.
- Primary key identifies each item:
  - Partition key distributes data.
  - Sort key orders items with the same partition key.
- GSI lets you query using a different key.
- `Query` reads matching keys; `Scan` reads the whole table.
- Choose on-demand or provisioned capacity; avoid hot partition keys.
- Supports eventual and strong reads, conditional writes, transactions, and TTL.
- Best for predictable, high-scale access patterns; poor fit for joins and ad-hoc analytics.
