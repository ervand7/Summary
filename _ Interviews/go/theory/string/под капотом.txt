type stringStruct struct {
    str unsafe.Pointer // Pointer to underlying bytes
    len int            // Length in bytes
}


Strings in Go are immutable sequences of bytes, not necessarily valid UTF-8. A UTF-8 encoded Unicode code
point occupies 1-4 bytes.

Memory and performance:
- `len(s)` returns the number of bytes, not characters.
- `range` iterates over Unicode code points (runes), returning byte offsets.
- `s[a:b]` normally shares underlying memory without copying.
- Small substrings can keep large underlying strings in memory. This is memory problem.
- `strings.Clone(s)` explicitly copies the string.
