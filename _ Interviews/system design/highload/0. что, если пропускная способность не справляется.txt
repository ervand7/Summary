When our service struggled to handle high RPS, we used several approaches:

1. Horizontal Scaling: Configured Kubernetes HPA to automatically scale pods based on CPU utilization.
2. Code & Database Optimization: Used profiling to identify bottlenecks, optimized algorithms and SQL
queries, and eliminated N+1 queries.
3. Caching: Introduced Redis and application-level caching to reduce database load and latency.
4. Load Balancing: Distributed incoming requests across multiple service instances.
5. Rate Limiting: Limited incoming traffic to prevent overload and protect downstream dependencies.
6. Monitoring & Alerting: Used Prometheus and Grafana to track RPS, p95/p99 latency, CPU, memory, and
error rates.

Key principle: Identify the bottleneck first, optimize resource usage, and scale horizontally without
overwhelming downstream dependencies.
