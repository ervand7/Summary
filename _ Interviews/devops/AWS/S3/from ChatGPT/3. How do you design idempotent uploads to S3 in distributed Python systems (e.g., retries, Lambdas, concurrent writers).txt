Scenario:
1. Client → API Gateway → Lambda: Sends an upload request with an `idempotency_key`.
2. Lambda → DynamoDB: Checks if the key already exists.
3. If completed: Returns the existing S3 object key.
4. If new: Atomically reserves the key in DynamoDB and generates an S3 pre-signed URL.
5. Client → S3: Uploads the file directly using the URL.
6. Lambda: After upload confirmation, marks the operation as completed in DynamoDB.

Result: Retrying the same request reuses the existing upload instead of creating duplicates.
